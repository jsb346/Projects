# ⚾ MLB Player Performance Analysis  

## 📌 Project Overview  
This project analyzes MLB player performance using **StatCast data**, focusing on key metrics such as **exit velocity, launch angle, and spin rate**.  

## 📊 Data Sources  
- [StatCast API](https://baseballsavant.mlb.com/) (Advanced MLB metrics)  
- [Lahman Database](https://www.seanlahman.com/baseball-archive/statistics/) (Traditional stats)  

## 🛠 Tech Stack  
- **Python** (`pandas`, `matplotlib`, `seaborn`) OR  
- **R** (`tidyverse`, `ggplot2`)  

## 🔍 Questions to Explore  
- What separates **elite hitters** from average hitters?  
- How does **exit velocity** impact batting average?  
- Are **high-spin pitchers** better at preventing home runs?
